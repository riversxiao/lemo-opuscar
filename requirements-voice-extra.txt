# already available from the voice/core stack — no extra pip required for the client.
# Point LEMO_TTS_QWEN3_BASE or LEMO_TTS_OMNIVOICE_BASE at YOUR server; optional
# LEMO_TTS_*_API_KEY only if that server demands one. Never commit keys.
#
# Create kokoro venv (Python 3.11–3.13):
#   uv venv .venv-voice --python 3.12
#   uv pip install --python .venv-voice/bin/python kokoro-onnx soundfile numpy edge-tts
#
# Do not pip-install multi-GB model wheels into the lemo .venv by default.
