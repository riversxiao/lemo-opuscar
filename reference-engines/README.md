# reference-engines

Optional extra engines produced by Claude Opus / Claude Code for styles where Flash needs a stronger base than the stock `styles/<slug>/demo/`.

Layout: `reference-engines/<slug>/` with the same shape as a style demo (`index.html`, `film.js` / `main.js`, …) plus a short `SOURCE.md` (model, date, license, what Flash may edit).

Stock demos under `styles/*/demo/` are already Opus 5.5 references — add files here only when you have an improved or custom engine.
